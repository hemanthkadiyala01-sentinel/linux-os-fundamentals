# Evidence-First Investigation Method

1. State the question and authorized systems.
2. Capture the least-invasive evidence source and collection time.
3. Establish normal behavior before calling an event unusual.
4. Preserve event context: timestamp, account, host, source, and outcome.
5. Separate observations from inferences and record alternative explanations.
6. Redact sensitive data before committing evidence.
7. Record access limitations and do not turn missing visibility into a claim.

This method is used by the three hunts in `labs/06-threat-hunting`.
